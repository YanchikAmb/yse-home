# Образы прошивок

Сервис отдаёт образ той модели, которую выбрали на странице. Файлы кладут сюда на сервере до запуска. В git архивы и разделы не входят.

| Каталог | Модель |
| --- | --- |
| `yandexmidi/` | Станция 2 |
| `yandexmini_2/` | Мини 2 |
| `yandexstation_2/` | Станция Макс |

В каталог Макса не кладут сборку `5000000896` (апрель 2022): её применение может зациклить перезагрузку.
