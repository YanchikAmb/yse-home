# Своя оболочка для Яндекс Станции

Колонка остаётся колонкой: микрофоны, динамик, подсветка. Диалог, музыка и команды дома идут через ваш сервер.

Проверено на трёх моделях: Станция 2, Мини 2 и Макс.

## Из чего состоит

- **Свой DNS.** Колонки спрашивают имена у этого сервиса. Он отвечает своим адресом, поэтому обновление и имена приходят к вам, а не в облако Алисы.
- **Своя страница сервиса.** Список колонок, поиск уже переделанных, кнопки «Переделать», «Открыть», «Прошита».
- **Своя страница на каждой колонке.** Слово, голос, музыка, будильники, эквалайзер, подсветка. У Станции 2 и Мини 2 это оболочка на самой колонке. У Макса — своё приложение.
- **Своя озвучка.** Голоса «Джарвис» и «Вихров» уже в репозитории. Голос Яндекса включается после входа в свой аккаунт на странице колонки: музыка и ответы Яндекса идут с этого входа.
- **Распознавание на вашем компьютере.** Whisper и GigaAM. Отдельный облачный ключ для этого не нужен.
- **Google, режим ИИ.** Вопрос пишется в чат поиска Google, ответ читается вслух. В аккаунт Google входят один раз.
- **Дообучение слова «Джарвис»** на голоса семьи, кнопка на странице колонки.
- **Home Assistant.** Интеграция ставится в Home Assistant и сама подключается к колонке: плеер, свет, слово, голос, гарнитура.
- **Гарнитура.** Колонку можно включить как Bluetooth-гарнитуру телефона: голосом «включи гарнитуру» или переключателем в Home Assistant.
- **Своя связь с аккаунтом Яндекса.** Вход делается на странице колонки, кодом с телефона. Один вход достаётся всем колонкам дома.

## Что понадобится

- Компьютер в одной сети с колонками, с Docker и видеокартой NVIDIA. Он должен быть включён, пока вы пользуетесь колонками. На нём крутятся распознавание, голос и обучение.
- Роутер, где **каждой** подключаемой колонке можно прописать DNS. Телефонам, компьютерам и прочим устройствам этот DNS не ставьте: сервис отвечает на все имена своим адресом, и у них пропадёт обычный интернет.
- Колонка, которую можно сбросить к заводским настройкам. После сброса её снова добавляют в приложение «Дом с Алисой» и в вашу сеть. Без этого она не запросит обновление, и сервис её не увидит.

## Поставить сервер

1. Склонируйте репозиторий и перейдите в него.

   ```
   git lfs install
   git clone https://github.com/YanchikAmb/yse-home.git
   cd yse-home
   git lfs pull
   ```

   Прошивки трёх моделей и файлы, без которых колонка не примет сервис, уже в репозитории. Ничего отдельно скачивать и подменять не нужно. Архив Макса идёт через Git LFS: если вместо большого файла лежит короткий текст, снова выполните `git lfs pull`.

2. Скопируйте пример настроек и впишите свою сеть.

   ```
   cp .env.example .env
   ```

   | Строка | Что вписать |
   | --- | --- |
   | `YSE_IP` | Свободный адрес в вашей сети. Это страница сервиса, DNS колонок и адрес, куда колонка отправляет слово и фразу |
   | `YSE_NIC` | Сетевая карта этого компьютера в той же сети, что и колонки. По ней сервис занимает `YSE_IP`. Имя показывает `ip link`, часто `eth0` |
   | `YSE_SUBNET` | Ваша сеть, например `192.168.1.0/24` |
   | `YSE_GW` | Шлюз, обычно адрес роутера |

   Порты колонкам назначает сервис. Адрес Home Assistant здесь не нужен: интеграция подключается из Home Assistant к колонке.

3. Запустите.

   ```
   docker compose up -d --build
   ```

   Первый запуск долгий: контейнеры сами скачивают модели и собирают окружение голоса и слова. Повторный запуск этого не повторяет.

4. Откройте `http://АДРЕС_ИЗ_YSE_IP:8090/`. Должна открыться страница со списком «Колонки». Пока пусто — это нормально.

   С этого же компьютера страница открывается, если свободен соседний адрес: последнее число в `YSE_IP` минус один. Если он занят, с этой машины страница не откроется. С телефона и с других компьютеров она открывается по `YSE_IP`.

Проверка, что DNS сервиса отвечает колонке:

```
nslookup quasar.yandex.net АДРЕС_ИЗ_YSE_IP
```

В ответе должен быть тот же адрес, что в `YSE_IP`.

## Подключить колонку

1. На роутере каждой колонке, которую подключаете, укажите DNS — адрес из `YSE_IP`.
2. Сбросьте колонку к заводским настройкам, подключите её к вашему Wi‑Fi и снова добавьте в «Дом с Алисой». Без повторного добавления она не запросит обновление.
3. Откройте `http://АДРЕС:8090/`. Колонка появляется, когда спрашивает обновление. До кнопки сервис прошивку не отдаёт. Нажмите «Переделать».
4. Когда оболочка встала, у этой колонки в списке нажмите «Открыть». Откроется её страница: слово, голос, музыка, будильники, вход в Яндекс и Google. Как пользоваться: [speaker/docs/usage.md](speaker/docs/usage.md).

Уже переделанная колонка обновление не запрашивает. На странице сервиса впишите подсеть и нажмите «Найти колонки в сети». Потом «Проверить» и «Прошита». Надпись «прошита» появляется только после этой кнопки. Ключ страницы показан у отмеченной колонки: его просит интеграция Home Assistant.

| Модель | Что делает «Переделать» |
| --- | --- |
| Станция 2 | Отдаёт прошивку, отключает обновления Яндекса, ставит оболочку |
| Мини 2 | То же самое |
| Макс | Отдаёт сборку `5000000896`. На ней ставится своё приложение и один раз открывается доступ к матрице часов и кольцу. Колонка при этом может перезагрузиться |

Для Макса один раз соберите приложение по [yse-max](https://github.com/YanchikAmb/yse-max) и положите файл в `max/station.apk`. Адрес сервиса приложение получает при установке. На сборке новее `5000000896` этот путь не работает.

В Google входят один раз: на этом компьютере откройте VNC, порт 5900, и войдите в аккаунт. Вход сохраняется.

## Home Assistant

Интеграция ставится в Home Assistant и сама ходит к колонке. Адрес Home Assistant в настройках сервиса не нужен.

1. В HACS откройте меню (три точки) → Custom repositories.
2. Адрес: `https://github.com/YanchikAmb/yse-home`, тип Integration.
3. В списке интеграций найдите Yandex Station и нажмите «Скачать».
4. Перезапустите Home Assistant.
5. Настройки → Устройства и службы → Добавить интеграцию → Yandex Station. Укажите IP колонки и ключ её страницы. Ключ показан на странице сервиса у колонки, которую вы отметили «Прошита».

Компонент видит колонки, на которых уже стоит оболочка: плеер, свет, слово, голос, гарнитура.

## Дообучение

Кнопка «Обучить» на странице колонки. Нужна видеокарта. Первая модель «Джарвис» уже обучена. Как дообучить на голоса семьи и как учить слово с нуля: [docs/train.md](docs/train.md).

## Если колонка молчит или пишет «нет интернета»

- Страница `:8090` не открывается с другого устройства — сервис не запущен или адрес `YSE_IP` занят. Посмотрите `docker compose ps` и `docker compose logs`.
- Страница не открывается только с этого компьютера — занят соседний адрес (последнее число `YSE_IP` минус один).
- `nslookup quasar.yandex.net` не возвращает `YSE_IP` — у колонки в роутере указан другой DNS, либо порт 53 на этом компьютере занят другой программой.
- Колонка после сброса не появляется — её не добавили обратно в «Дом с Алисой», поэтому она не запросила обновление.
- Макс сброшен, а приложения нет — в `max/station.apk` нет собранного приложения.
