# Один сервис для Яндекс Станций

Сюда входят DNS, прошивки, страница и оболочки Станции 2 и Мини 2. Приложение Станции Макс — отдельный репозиторий [yse-max](https://github.com/YanchikAmb/yse-max). Его собирают под адрес этого сервера и ставят с той же страницы.

Колонку не настраивают в консоли. Человек делает четыре вещи:

1. Поднимает этот сервис в сети колонок.
2. На странице `http://IP_СЕРВИСА:8090/` добавляет колонку: IP и модель (Макс, Станция 2, Мини 2).
3. В DNS колонки ставит только IP сервиса. Остальной дом не переводит и правил на роутере не делает.
4. Сбрасывает колонку.

DNS сервиса отвечает на любое имя своим адресом (`DNS_SINK_ALL`). Запросы на порты 80 и 443 приходят на сервис сами: обновления Яндекса он не отдаёт, остальной HTTPS пропускает по имени сервера. Порты кроме 80 и 443 (время, мессенджер) этот DNS не проксирует.

## Что лежит где

| Каталог | Зачем |
| --- | --- |
| `stand/` | DNS, HTTPS, прошивки, страница `:8090` |
| `speaker/` | Оболочка Станции 2 и Мини 2, распознавание, ответы, музыка |
| `firmware/yandexmidi/` | Образ Станции 2. В git образа нет |
| `firmware/yandexmini_2/` | Образ Мини 2. В git образа нет |
| `firmware/yandexstation_2/` | Каталог Макса. Сборку `5000000896` (апрель 2022) Максу не отдавать: применение может зациклить перезагрузку |
| [yse-max](https://github.com/YanchikAmb/yse-max) | Только APK. `HOST` и `BASE` в `Web.java` — адрес и порты этого сервера |

Правка ответов, портов или слова в `speaker/` касается всех трёх моделей: Макс ходит в тот же блок портов. Правка DNS и прошивки — в `stand/` и `firmware/`. Правка экрана, слова «Алиса» и Wi‑Fi при воткнутом кабеле — в `yse-max`. Сервис только ставит уже собранный APK.

## Поднять сервис

Нужны Docker и свой адрес в сети колонок. Сертификат HTTPS (`certs/fullchain.pem` и `certs/quasar-all.key`) на сервер кладут при установке, в git их нет.

```
cp .env.example .env
```

В `.env` указывают `YSE_IP`, сеть и интерфейс. Образы прошивок кладут в каталоги `firmware/<платформа>/` до запуска. Затем:

```
docker compose up -d --build
```

Страница: `http://YSE_IP:8090/`. Форма «Колонки» сохраняет IP и модель в `run/columns.json`.

Проверка DNS с другой машины, где резолвером указан `YSE_IP`:

```
nslookup quasar.yandex.net YSE_IP
nslookup example.com YSE_IP
```

Оба имени должны ответить адресом сервиса.

## После сброса колонки

| Модель | Что делает сервис |
| --- | --- |
| Станция 2 | Отдаёт образ из `firmware/yandexmidi/`, закрывает обновления Яндекса, открывает SSH `:2222`, ставит оболочку |
| Мини 2 | То же из `firmware/yandexmini_2/`. Пресет `yandexmini_2`, захват `hw:0,1`, порог слова `0.85` |
| Макс | Образ из `firmware/yandexstation_2/` есть в каталоге, но заводской Макс сам ADB не открывает, и сборку апреля 2022 ему не отдают. Когда порт 5555 уже открыт, сервис ставит APK из `yse-max`, отзывает микрофон у `com.yandex.io.sdk` и выключает `com.yandex.tv.alice`. Пакет `com.yandex.io.sdk` не отключают. Псевдорут не нужен и не запускается |

На чистом Максе приём `quasar.yandex.net`, который открывает root-ADB на Станции 2, не включает ADB. Пока порт 5555 закрыт, установка APK останавливается. Как открыть его на заводском Максе без ручного ADB, ещё не сделано.

Ключи, пароли и `site.json` в git не кладутся.
