# Своя оболочка для Яндекс Станции

Колонка остаётся колонкой: микрофоны, динамик, подсветка. Диалог, музыка и команды дома идут через ваш сервер, а не через облако Алисы.

Подходят три модели: Станция 2, Мини 2 и Макс. Приложение для Макса лежит отдельно: [yse-max](https://github.com/YanchikAmb/yse-max).

## Что понадобится

- Компьютер в одной сети с колонкой, с Docker. Он должен быть включён, пока вы пользуетесь колонкой.
- Роутер, в котором у **одной** колонки можно прописать DNS-сервер. Остальным устройствам DNS менять не нужно.
- Сама колонка и возможность сбросить её к заводским настройкам. Сброс отвяжет аккаунт Яндекса.

## Один раз поставить сервер

1. Склонируйте репозиторий и перейдите в него.

   ```
   git clone https://github.com/YanchikAmb/yse-home.git
   cd yse-home
   ```

2. Скопируйте пример настроек и впишите свою сеть.

   ```
   cp .env.example .env
   ```

   | Строка | Что вписать |
   | --- | --- |
   | `YSE_IP` | Свободный адрес в вашей сети. Его получит сервис, его же вы укажете колонке как DNS |
   | `YSE_NIC` | Сетевой интерфейс этого компьютера, например `eth0`. Имя показывает `ip link` |
   | `YSE_SUBNET` | Ваша сеть, например `192.168.1.0/24` |
   | `YSE_GW` | Шлюз, обычно адрес роутера |
   | `YSE_SHIM_IP` | Ещё один свободный адрес. С него этот компьютер открывает страницу сервиса |
   | `YSE_VOICE_HOST` | Адрес этого компьютера, как его видит колонка. Сюда она шлёт слово и фразу. Это не `YSE_IP`: `YSE_IP` — адрес страницы сервиса |
   | `YSE_VOICE_BASE` | Первый порт блока колонки. Оставьте `18805`, если порт свободен |

   `YSE_LOCK_SKIP` оставьте пустым.

3. Сертификат, которому колонка уже доверяет, уже лежит в `certs/`: `fullchain.pem` и `quasar-all.key`. Свой самоподписанный она отвергнет, эти файлы не заменяйте.

4. Прошивки уже лежат в `firmware/`: Станция 2, Мини 2 и Макс, у каждой свой `manifest.json` и архив. Для архива Макса нужен Git LFS. Перед клонированием: `git lfs install`. Если каталог уже скачан и вместо архива короткий текстовый файл, выполните `git lfs pull`.

   Для Макса в каталоге сборка `5000000896` (апрель 2022, отпечаток `PPR1.180610.011`). На ней открывается ADB. Более новая сборка, которую предлагает облако Яндекса, этот путь ломает.

5. Запустите сервис.

   ```
   docker compose up -d --build
   ```

6. Откройте в браузере `http://АДРЕС_ИЗ_YSE_SHIM_IP:8090/` с этого компьютера или `http://АДРЕС_ИЗ_YSE_IP:8090/` с другого. Должна открыться страница со списком «Колонки». Пока пусто — это нормально.

7. Поставьте слово, распознавание и голос на этот же компьютер. Нужны Python 3 и SSH на него (Ubuntu). Из каталога `speaker`:

   ```
   python install/yse_station_setup.py init
   python install/yse_station_setup.py all --yes
   ```

   `init` спрашивает адрес компьютера, пользователя SSH и Home Assistant. На вопросы про чужую колонку, архив soda, свою модель слова и токен Яндекса нажмите Enter. Слово «джарвис» и голоса «Джарвис» и «Вихров» уже лежат в `models/`, установщик сам кладёт их на компьютер. Без soda фраза распознаётся здесь. Свой голос работает без входа в Яндекс. Голос Яндекса включается после входа на странице колонки. В Google «Режим ИИ» входят один раз через VNC, порт 5900. Этот вход установщик не стирает.

8. Для Макса соберите APK по [yse-max](https://github.com/YanchikAmb/yse-max) и положите его в `max/station.apk`, затем `docker compose up -d`. Адрес из `YSE_VOICE_HOST` сервис запишет в приложение сам. Строки в `Web.java` — запасной адрес, если `YSE_VOICE_HOST` пустой.

Проверка с другого компьютера в той же сети:

```
nslookup example.com АДРЕС_ИЗ_YSE_IP
```

В ответе должен быть тот же адрес, что в `YSE_IP`. Если там адрес Яндекса или `8.8.8.8`, колонка до сервиса не дойдёт.

## Подключить колонку

1. На роутере найдите эту колонку и только ей укажите DNS-сервер — адрес из `YSE_IP`. Весь её трафик на роутере перенаправлять не нужно: колонка сама спросит имена у этого DNS, а сервис ответит своим адресом.
2. Сбросьте колонку к заводским настройкам и дайте ей подключиться к вашему Wi‑Fi.
3. Откройте `http://АДРЕС:8090/`. Колонка появляется в списке, когда спрашивает у этого DNS имя `quasar` или `scbh`. Проверка связи и прочие имена её не создают.
   - Заводская: она запросит обновление, в запросе будет идентификатор модели. До кнопки сервис прошивку не отдаёт. Нажмите «Переделать».
   - Уже с нашей оболочкой: обновление она не запрашивает. На странице впишите подсеть и нажмите «Найти колонки в сети». Сервис ищет в ней порт `18080` и ответ `/api/clock`. Поле сначала предлагает сеть адреса самого сервиса (`/24`), её можно заменить. Повторного поиска нет: только эта кнопка. «Проверить», затем «Прошита». У Станции 2 и Мини 2 ключ читается по SSH. У Макса SSH нет: ключ читается по ADB из приложения. Надпись «прошита» появляется только после этой кнопки.

Дальше сервис делает это сам.

| Модель | Что происходит после сброса |
| --- | --- |
| Станция 2 | Сервис отдаёт прошивку, отключает обновления Яндекса и ставит оболочку. На колонке открывается вход по SSH, порт 2222 |
| Мини 2 | То же самое |
| Макс | Сервис отдаёт сборку `5000000896`. На ней включается ADB, порт 5555, и ставится приложение из `max/station.apk`. На этой сборке сервис один раз открывает root, чтобы приложению были доступны матрица часов и кольцо. Колонка при этом может перезагрузиться |

Когда оболочка встала, страница самой колонки — `http://IP_КОЛОНКИ:18080/`. С неё выбираются слово, голос, музыка и будильники. Как пользоваться: [speaker/docs/usage.md](speaker/docs/usage.md).

Приложение Макса — [yse-max](https://github.com/YanchikAmb/yse-max). Готовый файл кладётся в `max/station.apk`. Куда слать звук, приложение читает из файла, который сервис пишет при установке.

## Home Assistant

Компонент ставится из HACS, не вручную в папку.

1. В HACS откройте меню (три точки) → Custom repositories.
2. Адрес: `https://github.com/YanchikAmb/yse-home`, тип Integration.
3. В списке интеграций найдите Yandex Station и нажмите «Скачать».
4. Перезапустите Home Assistant.
5. Настройки → Устройства и службы → Добавить интеграцию → Yandex Station. IP колонки и ключ её страницы. Ключ показан на странице сервиса у колонки, которую вы отметили «Прошита». Его создаёт установка оболочки, файл на колонке: `/data/opt/yandex-station/token`.

Компонент видит колонки, на которых уже стоит оболочка: плеер, свет, слово, голос.

## Голос, музыка и обучение

Слово, ответы, музыка, Whisper, GigaAM, голоса «Джарвис» и «Вихров», чат Google «Режим ИИ», обучение и спутник Home Assistant ставятся шагом 7 выше. Отдельный проект для них не нужен.

Дообучить «джарвис» на голосах семьи: [docs/train.md](docs/train.md). Кнопка на странице колонки, нужен компьютер с видеокартой. Первая модель «джарвис» уже обучена. С нуля новое слово учится дольше, это тоже описано там.

## Если колонка молчит или пишет «нет интернета»

- Страница `:8090` не открывается — посмотрите `docker compose ps` и `docker compose logs`. Сервис должен быть запущен, адрес `YSE_IP` свободен.
- `nslookup` не возвращает `YSE_IP` — DNS колонки смотрит не на сервис, либо порт 53 занят другой программой на этом компьютере.
- Станция 2 или Мини 2 так и не получили оболочку — в `firmware/` нет архива именно этой модели, либо колонка не была сброшена после смены DNS.
- Макс сброшен, а приложения нет — порт 5555 закрыт. Пока он закрыт, добавление на странице только запоминает колонку.
