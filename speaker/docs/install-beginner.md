# Установка простыми словами

Для того, кто делает это впервые. Обычный путь для нового дома — [home.md](home.md): поднять сервис, назвать IP и модель колонки, отдать ей DNS стенда и сбросить. Ниже — тот же сервер, если root на колонке уже есть. Все подробности — в [install.md](install.md).

## Что получится

Яндекс Станция перестаёт слушать Яндекс. Она откликается на «джарвис», играет вашу Яндекс Музыку, ставит будильники голосом, управляет домом через Home Assistant и отвечает на вопросы голосом Алисы или своим. Что именно можно говорить — [usage.md](usage.md).

## Что понадобится

1. **Колонка с root.** Яндекс Станция 2 или Станция Мини 2, на которой уже открыт вход root по SSH на порту 2222 без пароля. Как его получить, здесь не описано.
2. **Домашний сервер.** Любой компьютер, который всегда включён: Ubuntu 22.04, 8 ГБ памяти, 20 ГБ свободного места. Видеокарта нужна только для «умного» распознавания и своего голоса.
3. **Home Assistant OS** с дополнением «Advanced SSH & Web Terminal». В настройках дополнения задать пароль и выключить «Protection mode».
4. **Компьютер, с которого всё запускается.** Подойдёт Windows: поставить Python 3.11+ с [python.org](https://www.python.org/downloads/) (галка «Add Python to PATH»), затем в PowerShell `pip install paramiko`.
5. **Необязательно: каталог `soda/`** (распознавание речи Google прямо на Станции 2, как голосовой ввод на телефоне). Без него фразу распознаёт сервер. Если он у вас есть, путь к архиву указывается в `init`.
6. **Токен Яндекса** — файл с OAuth-токеном вашего аккаунта, одной строкой: им колонка говорит голосом Алисы. Модель слова «джарвис» установщик скачает сам из Releases репозитория.

## Один раз на дом

1. Скачать проект: на странице репозитория Code → Download ZIP и распаковать, например в `D:\yandex-station`. Или `git clone`.
2. Открыть PowerShell в этой папке.
3. Ответить на вопросы про свой дом:
   ```
   python install\yse_station_setup.py init
   ```
   Спросит адрес сервера, имя пользователя, адрес HA, подсеть, адрес Станции 2 и где лежит модель слова. Где не знаете — нажмите Enter. Ответы сохранятся в `install\site.json`. Этот файл никому не отправлять.
4. Поставить всё на сервер:
   ```
   python install\yse_station_setup.py all --yes
   ```
   Спросит пароль сервера и пароль SSH в HA. Первый раз займёт 20–40 минут. В конце: «Готово». Home Assistant один раз перезапустится.

Если есть видеокарта NVIDIA: `python install\yse_station_setup.py all --yes --stt --voice`.

## Каждая новая колонка

1. Колонка с root должна быть в той же домашней сети.
2. Примерно через минуту в HA появится «Обнаружено: Колонка 107» (число — конец IP колонки). Настройки → Устройства и службы → «Добавить» → «Подтвердить».
3. Подождать 5–30 минут. Окно можно закрыть. Колонка один раз перезапустит свои программы. Из розетки в это время не вынимать.
4. Когда установка закончится, открыть устройство «Колонка 107» → карандаш → дать имя и **выбрать комнату**. По комнате колонка понимает, какой свет включать на «включи свет».
5. Скажите «джарвис» — кольцо загорится.

Если колонка не появилась:

- подождите ещё 2 минуты;
- проверьте root: на сервере `ssh -p 2222 root@IP_КОЛОНКИ echo ok` должно напечатать `ok`;
- колонку, на которой оболочка уже стоит, сервер повторно не предлагает.

Если HA написал «Установка не удалась» — журнал на сервере в `/storage/yse/jobs/`.

## Страница колонки

1. В браузере открыть `http://IP_КОЛОНКИ:18080`.
2. Вверху поле для ключа. Ключ покажет команда
   ```
   python install\yse_station_setup.py key --ip IP_КОЛОНКИ
   ```
   Скопировать в поле и нажать «Открыть». Браузер запомнит.
3. Музыка: войти в Яндекс по коду с телефона. Вход достаётся всем колонкам дома.
4. Будильники, эквалайзер, голос, нейросеть, слово — всё там же. Описание — [usage.md](usage.md).

## Обновить

Скачать свежую версию проекта в ту же папку (`install\site.json` не трогать) и выполнить

```
python install\yse_station_setup.py all --yes
```

Колонки обновятся сами в течение 3 минут. Музыка и слово не прерываются.

## Если что-то не так

- Не откликается на «джарвис»: перезагрузить колонку из розетки и подождать 2 минуты. Не помогло — на сервере `journalctl -u yse-wake@st107 -n 30` (107 — конец IP колонки).
- Страница пишет «ключ не подошёл»: взять ключ заново командой `key`.
- Музыка не играет: на странице войти в Яндекс ещё раз.
- Остальное — таблица «Неполадки» в [install.md](install.md#неполадки).

Никому не отправляйте ключ страницы, `install\site.json`, пароли и токен Яндекса.
