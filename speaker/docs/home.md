# Один сервис на весь дом

Стенд (DNS и прошивки) и оболочки колонок — один сервис. Отдельного проекта «только стенд» для нового дома нет. Приложение Макса лежит отдельно: [station-max](https://github.com/YanchikAmb/station-max). Его собирают под адрес этого сервиса и ставят с панели.

Человек делает четыре вещи. Остальное делает сервис.

1. Один раз поднимает сервис. Колонки в DNS указывают только IP сервиса, остальной дом не переводят.
2. На странице сервиса (`http://IP_СЕРВИСА:8090/`) добавляет колонку: IP и модель (Макс, Станция 2, Мини 2). Консоли нет.
3. В DNS колонки ставит IP сервиса.
4. Сбрасывает колонку.

DNS сервиса отвечает на любое имя своим адресом. Отдельное правило на роутере не нужно: запросы на порты 80 и 443 приходят на сервис сами.

## Что сервис делает сам

| Модель | На странице | После сброса на DNS сервиса |
| --- | --- | --- |
| Станция 2 | Станция 2 | Сервис отдаёт прошивку из `firmware/yandexmidi/`, закрывает обновления Яндекса (`yandex-noupdate.sh`), открывает SSH `:2222` и ставит оболочку. |
| Мини 2 | Мини 2 | Тот же путь, каталог `firmware/yandexmini_2/`. В конфиг пишутся пресет `yandexmini_2`, захват `hw:0,1` и порог слова `0.85`. |
| Станция Макс | Макс | Каталог `firmware/yandexstation_2/` есть, но сборку апреля 2022 (`5000000896`) Максу не отдают: применение может зациклить перезагрузку. Когда открыт ADB `:5555`, сервис ставит APK, отзывает микрофон у `com.yandex.io.sdk` и выключает `com.yandex.tv.alice`. Пакет `com.yandex.io.sdk` не отключается. Псевдорут не запускается. |

На чистом Максе сетевой ADB сам не включается: приём `quasar.yandex.net`, который открывает root-ADB на Станции 2, на Максе не работает. Пока порт 5555 закрыт, установка APK останавливается. Как открыть его на заводском Максе без ручного ADB, ещё не сделано.

## APK Макса

В `station-max` правятся только само приложение и подстановка адреса сервиса. В `Web.java` это `HOST` (IP сервера голоса) и `BASE` (первый порт блока этой колонки). Готовый APK сервис ставит сам. В git образа нет.

## Что от чего зависит

- Правка `yse_talk.py`, портов или слова касается и Станции 2, и Мини 2, и Макса. Макс ходит в тот же `BASE`.
- Правка прошивки и DNS касается сервиса. Образы лежат в `firmware/<платформа>/` на сервере и в git не коммитятся.
- Правка экрана, споттера «Алиса» и Wi‑Fi при воткнутом кабеле живёт в `station-max`. Сервис только ставит собранный APK.

Пароли, `site.json`, ключ страницы и ключи стенда в git не кладутся.
