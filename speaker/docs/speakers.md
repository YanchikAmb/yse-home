# Какие колонки подходят

Пакет один для колонок с root: нужны armhf, glibc 2.30 и штатный шумодав `libyandex_evil.so`. Установщик проверяет это сам и на чужой колонке останавливается. Каталог на колонке — `/data/opt/yandex-station`, страница — порт 18080. Станция Макс сюда не входит: у неё нет root, приложение и установка описаны в [station-max.md](station-max.md).

| Колонка | Платформа | Работает | Как разбирается фраза |
| --- | --- | --- | --- |
| Яндекс Станция 2 | `yandexmidi` | да | на колонке (`soda/`) или на сервере, на выбор |
| Яндекс Станция Мини 2 (с часами) | `yandexmini_2` | да | на сервере |
| Станция Миди и другие поколения | — | не проверено, не ставить | — |
| Станция Макс (Android 9) | `yandexstation_2` | да, отдельным приложением, без root | на сервере. Этот пакет с root туда не ставится. См. [station-max.md](station-max.md) |
| Модуль, Лайт, Мини 1 | — | не проверено | — |

## Станция 2

- Корень диска перезаписываемый. Микрофоны: `hw:0,2`, 16 каналов, в шумодав идут первые 4. Пресет шумодава `yandexmidi`.
- Кольцо — экран `/dev/fb0` на 89 точек.
- Памяти хватает на распознавание на колонке: если есть `soda/` (около 125 МБ), его кладут на колонку. Без него или по выбору фразу разбирает сервер, как у Мини 2.
- Порог слова `0.9`.
- Есть датчик питания USB-C (ватты).

## Мини 2

- Корень только для чтения: установщик пишет в `/etc` через `mount -o remount,rw /` и сразу возвращает `ro`.
- Микрофоны: `hw:0,1`, 8 каналов, в шумодав первые 4, пресет `yandexmini_2`. Это нужно указать в `defaults` конфига (автоустановка делает сама).
- Логотип — шесть RGB в `/sys/class/leds/mini2:*:ring1..6`, часы — сегменты `mini2:white:clock*`: в покое время, на слово ярче, при таймере — обратный отсчёт.
- 244 МБ памяти, раздел данных около 89 МБ: распознавание на колонке не помещается.
- Фразу после слова статическое ухо `ear64s` отдаёт на сервер очищенным звуком (`settings/ear.engine=cloud`, `ear.src=clean`), текст считает выбранное распознавание. `soda/` не нужен.
- Порог слова `0.85`. Обёртка `aplay` дублирует моно во второй канал, иначе звук вдвое быстрее.
- Наушники: штекер уводит громкость колонки в ноль, без штекера она возвращается.

## Станция Макс

Отдельное Android-приложение `com.yse.station`, не этот репозиторий. Загрузчик залочен, root нет, установщик `speaker` колонку не трогает. Часы и кольцо остаются, микрофон у `com.yandex.io.sdk` только отзывается, пакет `com.yandex.tv.alice` выключен. Слова «алиса» и «яндекс» считает заводская модель внутри нашего процесса, диалог в облако Алисы не уходит. Сервер тот же, в окружении колонки `YSE_PLAY=http`.

Исходники, APK и установка: [station-max.md](station-max.md).

## Общие для обеих

- Quasar снимается с загрузки, его старт хранится в `S99quasar.saved` — колонку можно вернуть к Яндексу (см. [install.md](install.md#как-вернуть-колонку-к-яндексу)).
- Шумодав и команды без слова («дальше», «пауза», «громче») — штатные модели Яндекса на колонке.
- Датчик освещённости LTR-308, температура платы.
- Кнопка разговора: коротко — пауза, долго — слушать. Кнопки громкости шагают на 5%.
- Обновления прошивки Яндекса лучше закрыть (`speaker --noupdate`): новая прошивка может убрать root.
