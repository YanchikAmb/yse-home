# Станция Макс

Станция Макс (`yandexstation_2`) — Android 9 с залоченным загрузчиком. Root нет, SSH нет, каталога `/data/opt/yandex-station` нет. Установщик `speaker` из этого репозитория на неё не ставится: он рассчитан на Станцию 2 и Мини 2.

Оболочка Макса — отдельное приложение `com.yse.station`. Исходники и подписанный APK: <https://github.com/YanchikAmb/station-max>. Руководство по установке и сборке — README того репозитория. Здесь только то, что нужно состыковать с этим сервером.

## Что остаётся от этого репозитория

Сервер тот же: `yse-wake`, `yse-talk`, `yse-music`, по желанию спутник Wyoming и компонент Home Assistant. В окружении этой колонки обязательно `YSE_PLAY=http`. Сервер на колонку по SSH не ходит. Колонка сама шлёт звук и забирает ответ.

Приложение знает адрес сервера и базовый порт константами `HOST` и `BASE` в `Web.java`. Приложенный к релизу APK собран на `192.168.209.50` и базу `18805`. Для другого дома константы меняют и APK собирают заново.

| Порт | Служба | Содержимое |
| --- | --- | --- |
| `BASE` | `yse-wake` | UDP, кадры микрофона, `YSEMODE`, `YSEWAKE` |
| `BASE + 1` | `yse-music` | HTTP, музыка |
| `BASE + 3` | `yse-talk` | HTTP, фраза и ответ |
| `BASE + 5` | `yse-talk` | TCP, звук фразы |

Пока на колонке выбраны «Джарвис локально», «Алиса» или «Яндекс», она шлёт `YSEMODE`. Серверное слово «джарвис» в эти секунды её не будит. Срабатывание приходит готовым пакетом `YSEWAKE`.

`YSE_SPEAKER` — только первый адрес. Дальше ответ уходит туда, откуда на порт `BASE` приходят кадры микрофона. Переход с кабеля на Wi‑Fi и обратно меняет адрес сам, окружение править не нужно.

Звук фразы колонка отдаёт без усиления. Тихие кадры поднимает `yse-talk` перед VAD, отдельно на каждом кадре, с ограничением усиления. Общее умножение всей фразы на колонке портит узнавание голоса.

Короткая пустая фраза сразу после сигнала — эхо сигнала. `YSE_QUIET_RMS` (рабочее значение 500) такие фразы не озвучивает. Следующая фраза, уже с речью, обрабатывается как обычно.

Если в Home Assistant у погоды температура пустая (`null`), ответ погоды не должен бросать исключение: оборванный запрос колонка никак не озвучивает. Нет числа — говорится, что данных о погоде нет.

## Чего на колонке не делать

- Не отключать пакет `com.yandex.io.sdk`. Гаснет звуковой тракт. Запрещается только `RECORD_AUDIO`.
- Не включать `com.yandex.tv.alice`. Она забирает часы, кольцо и диалог. Слово «Алиса» считается библиотекой из её APK, но внутри `com.yse.station`.
- Не разблокировать загрузчик.

Команды установки и проверка, что запреты пережили перезагрузку, — в README репозитория приложения.
