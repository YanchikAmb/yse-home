# Своя оболочка для Яндекс Станции 2 и Станции Мини 2

Колонка остаётся железом: микрофоны, динамик, подсветка, кнопки, Wi‑Fi. Программу Яндекса (Quasar) снимаем с загрузки и вместо неё ставим свою оболочку. Тяжёлую работу делает домашний сервер: слово пробуждения, распознавание речи, ответы, музыка. Управление — со страницы на самой колонке и из Home Assistant.

## Что умеет

- Своё слово пробуждения «джарвис» (microWakeWord на сервере). Можно выбрать и штатные «алиса» и «яндекс». Слово можно дообучить на голосах своей семьи кнопкой «Обучить».
- Команды дома в Home Assistant с учётом комнаты, где стоит колонка: «включи свет», «закрой карниз». Несколько команд в одной фразе.
- Ответы на вопросы: голосовой помощник Яндекса, Assist в HA или любая нейросеть с API OpenAI (ChatGPT, Grok, локальная модель).
- Музыка из вашей Яндекс Музыки: «включи музыку», плейлисты, лайки, текст песни. Команды «дальше», «пауза», «громче» и другие работают без слова пробуждения, как у Алисы.
- Будильники: несколько на колонке, разовые и с повтором («по будням», «по выходным», «в пятницу», «каждый день»). Таймер.
- Сообщения между колонками: «передай в спальню, что ужин готов», «объяви всем…». Служба `yse_station.say` для автоматизаций.
- Эквалайзер, кольцо подсветки с эффектами, часы на Мини 2, датчик освещённости, гарнитура Bluetooth.
- Распознавание на выбор: Vosk, Whisper, GigaAM на своём сервере или Яндекс. Голос ответа: Алиса или свой (Silero + RVC).
- Home Assistant: плеер, свет, выбор нейросети и голоса, будильники, кнопки и сенсоры. Новая колонка с root сама появляется в HA как «Обнаружено» и ставится одной кнопкой.

Полный список команд — [docs/usage.md](docs/usage.md).

## Что нужно

| Что | Зачем |
| --- | --- |
| Яндекс Станция 2 (`yandexmidi`) или Станция Мини 2 (`yandexmini_2`) **с root** | Root (SSH dropbear на порту 2222 и вход без пароля) в этом проекте не описан, его нужно получить заранее |
| Яндекс Станция Макс | Другое приложение, без root. Сервер из этого репозитория, установка APK — [docs/station-max.md](docs/station-max.md) |
| Домашний сервер: Ubuntu 22.04, x86_64, 8 ГБ ОЗУ, около 20 ГБ на диске | Слово пробуждения, распознавание, ответы, музыка, сборка программ колонки |
| Видеокарта NVIDIA на сервере | Только для Whisper, GigaAM, своего голоса и дообучения слова. Без неё работает Vosk и голос Яндекса |
| Home Assistant OS с дополнением Advanced SSH & Web Terminal | Необязательно, но без HA нет команд дома и установки кнопкой |
| Компьютер с Python 3.10+ и `pip install paramiko` | С него запускается установщик (подойдёт и сам сервер) |
| Каталог `soda/` — необязательно | Google SODA для aarch64: распознавание речи прямо на Станции 2, без сервера. Не наш, в git его нет, на заводской колонке тоже. Без него фразу распознаёт сервер; Мини 2 он не нужен вовсе |
| Аккаунт Яндекса | Голос ответов, музыка |

Новый дом поднимается одним сервисом: сервер оболочек и стенд DNS/прошивок. Человек указывает IP колонки и модель (`max`, `station2`, `mini2`), ставит колонке DNS стенда и сбрасывает её. Дальше — [docs/home.md](docs/home.md). Приложение Макса собирается отдельно: [station-max](https://github.com/YanchikAmb/station-max).

## Быстрый старт

```
git clone https://github.com/YanchikAmb/yandex-station.git
cd yandex-station
pip install paramiko
python install/yse_station_setup.py init        # вопросы про ваш дом, пишет install/site.json
python install/yse_station_setup.py all --yes   # сервер, сборка, сторож, компонент HA
```

`all` повторяет безопасно: готовое пропускается. С видеокартой добавьте `--stt --voice`.

Дальше каждая колонка с root ставится сама: через минуту в HA появится «Обнаружено: Колонка NNN» → «Добавить» → «Подтвердить». Установка идёт 5–30 минут. После неё задайте колонке имя и комнату в HA, откройте её страницу `http://IP_колонки:18080` и войдите в Яндекс для музыки.

Подробно: [установка](docs/install.md), [установка простыми словами](docs/install-beginner.md).

## Что лежит в репозитории

| Каталог | Что |
| --- | --- |
| `src/` | программы колонки на C (armhf и aarch64): дом, ухо, страница, будильник, команды, эквалайзер |
| `www/` | страница колонки |
| `init/` | автозапуск на колонке и опрос обновлений |
| `host/` | службы сервера: слово, ответы, музыка, спутник HA, сторож, распознавание, голос |
| `install/` | установщик, связка с HA, шаблоны systemd, конфиги колонок |
| `ha/custom_components/yse_station` | компонент Home Assistant |
| `third_party/` | TensorFlow Lite Micro и microfrontend (Apache 2.0) |

Пароли, ключи, токены, модель слова и `soda/` в git не входят. Ключ страницы колонки создаётся при установке и хранится только на ней.

## Безопасность

- Страница колонки слушает порт 18080 в локальной сети и без ключа ничего не меняет. Не открывайте её в интернет.
- Сторож на сервере ставит оболочку только по запросу с адреса HA и только на найденную им колонку с root.
- В звуке настройки Wi‑Fi пароль сети лежит открыто: не включайте его при посторонних.
